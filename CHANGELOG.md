# Changelog

All notable changes to Hermes Deck are documented here. This project follows
[Semantic Versioning](https://semver.org/): the patch digit carries
backwards-compatible fixes only, the minor digit adds backwards-compatible
functionality.

## 1.1.0

### Added

- **Cron section.** Scheduled jobs with their schedule and a paused marker, read
  from `hermes cron list --all`. The `--all` flag is required: a paused job is
  stored as disabled and is hidden from the default listing, so without it a
  paused job would never appear. Inventory only — pausing and resuming stay in
  the CLI. New `showCron` setting, default on.
- **The panel scrolls.** Six sections in a card whose height is clamped to the
  screen previously meant everything past the fourth section was rendered below
  the bottom edge and could not be reached — no `Flickable`, no `ScrollView`, no
  `ScrollBar` existed anywhere. The content area now scrolls, with an as-needed
  scrollbar and arrow-key scrolling.
- **Security gates.** A secret/identity scanner and an image audit that run on
  every push, in CI, against the real system:
  - committed-blob scan for AWS, GitHub, Slack, OpenAI (legacy and the current
    prefixed forms), Anthropic, OpenRouter, Tavily, Google, HuggingFace, Stripe,
    JWT, Telegram and private-key shapes, plus machine identity (author name,
    home paths, hostname)
  - image audit over PNG text chunks, EXIF and OCR, because a screenshot is the
    one artifact no text scanner can read
  - a plain-text floor: every `Text`/`Label` must declare its format, so text
    that came from a session title or a model cannot be interpreted as markup
  - a clean-room check that fails the build if another plugin's code or
    identifiers appear in this tree
- **Cron fixture provenance.** The test fixture is generated by calling Hermes'
  own `cron_list`, and `--check` fails if it drifts from what the CLI prints, so
  the parser cannot quietly disagree with the real output.

### Fixed

- **Search never showed results.** Three compounding causes. Submitting a query
  set the service's query property but never triggered a collection; a slow
  refresh requested while one was in flight was silently dropped; and — the
  decisive one — the fast tick every five seconds reports an empty query, which
  overwrote the slow tick's answer within seconds. Measured directly: the slow
  tick returned 17 hits for "gateway", the fast tick five seconds later returned
  0. The panel therefore reported "0 conversation(s) matching" for every query.
  Results now survive a fast tick, and Clear removes the rows as well as the
  count.
- **The panel's last sections were unreachable** (see Added — this was a defect
  in every previous release, not just a consequence of adding Cron).
- **The bar pulse never animated.** Two dead references to the same halo: the
  opacity read a property from the animation instead of the element it targets,
  and a state-change handler called an id that exists nowhere in the file. The
  documented "cyan pulse while the agent works" now appears.
- **Cron rows showed no schedule.** The row rendered "active"/"paused", repeating
  state the marker, the colour and the section summary already conveyed, while
  the one useful field was missing and pushed off the row by a spacer that
  subtracted only two of its four siblings.
- **17 false negatives in the security gates**, including: a truncated metadata
  chunk reported as CLEAN while carrying a credential; the current OpenAI key
  format invisible because its prefix contains a hyphen; unquoted assignments in
  a `.env` invisible; UTF-16 files decoded with the wrong codec; a path present
  in `HEAD` but not the index never scanned, so a removed-but-published file
  audited clean.
- **6 crashes and unbounded-resource paths**, including a secret scan that spent
  20.5s spawning 17,456 subprocesses (now 0.43s), a 481 KB image that decoded to
  651 MB and could be reported as safe, and a filename of raw non-UTF-8 bytes
  that crashed the gate before it could emit any verdict.
- **A cron parser defect that fabricated a job and dropped a real one.** A job
  created without `--name` derives its display name from its prompt, and a
  multi-line prompt is printed verbatim — so a prompt containing an indented
  badge line rendered what looked exactly like a job header.
- **11 tests that passed for the wrong reason**, each repaired and confirmed to
  fail when its defect is reintroduced.

### Notes

- Nothing in 1.0.0 was removed or renamed. Settings, actions and the manifest
  contract are unchanged, so this is a drop-in upgrade.
- `Service.qml` changes only take effect on a shell restart: the plugin sets
  `keepLoaded: true`, so the shell contract does not replace a kept service
  instance on hot-reload. This is documented in `docs/TROUBLESHOOTING.md`.
