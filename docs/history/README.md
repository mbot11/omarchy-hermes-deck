# Historical design records

Superseded design and implementation documents, kept for the reasoning rather
than the specification. **Nothing here describes the current plugin.** For how
it works today, read `docs/ARCHITECTURE.md` and `CONSTRAINTS.md`.

| Document | Version | Superseded by |
|---|---|---|
| `DESIGN-v0.2.0.md` | v0.2.0 | `docs/ARCHITECTURE.md` |
| `PLAN-v0.2.0.md` | v0.2.0 | the v1.0.0 release |

They are here because a design record shows *why* a shape was chosen, which
`git log` alone does not. The code is the specification; these are the
argument that preceded it.
